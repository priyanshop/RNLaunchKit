# RN LaunchKit

A performance-minded React Native and TypeScript starter for production apps.

The complete source tree is available in [`RNLaunchKit-source.zip`](RNLaunchKit-source.zip). Download and unzip it to get the project folders, starter screen, strict TypeScript setup, navigation, Redux Toolkit, TanStack Query, typed API boundary, tests, CI, and contribution/security docs.

## Quick facts

- React Native 0.88 and React 19.3
- MIT licensed
- Early public preview; no external adoption or usage metrics are claimed
- Native `ios/` and `android/` shells are generated with the official React Native CLI; see the archive README for setup

The source archive preserves the project's folder structure and includes setup and contribution instructions.
